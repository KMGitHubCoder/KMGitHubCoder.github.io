Using Maps in Jupyter (VS Code) and GitHub

Why the map did not show in VS Code

  • Interactive maps (Folium / Plotly) rely on JavaScript.
  • VS Code blocks JavaScript in untrusted notebooks.
  • If you see Trust Notebook, the map will not render.
Fix: Click Trust Notebook, restart VS Code, restart the kernel, and re-run the cells.

Saving the map as HTML

When you run:

m.save("map.html")

The file is saved in the current working directory of the Jupyter kernel.

To check the exact location:

import os
os.getcwd()

Typical location

project/
├── notebook.ipynb
└── map.html

Opening the map

  • Right-click map.html in VS Code → Open with Default Browser
  • Or open it directly from your file system

GitHub connection explained

  • If your notebook is inside a GitHub repository, map.html is saved locally in that repo.
  • GitHub does not block file creation.
  • The file may appear as untracked in Source Control.

Common GitHub-related confusion

  • .gitignore may contain *.html
  • The file still exists but is ignored by Git

Verify the file exists

import os
print(os.path.exists("map.html"))
print(os.listdir())

If this prints True, the file exists regardless of GitHub.

Best practices

  • Save outputs to a dedicated folder (e.g. output/map.html)
  • Add generated HTML files to .gitignore if not needed in Git
  • Commit map.html only if you want to share or publish it

Optional: Publish via GitHub Pages

  • Commit map.html
  • Enable GitHub Pages
  • View your interactive map via a public URL

Key takeaway

Your map code is correct. The issue was VS Code notebook trust / renderer behavior — not GitHub.
