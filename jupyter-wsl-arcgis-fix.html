Fixing Jupyter Using ArcGIS (arcpy) Python Instead of WSL Python

Problem Summary

After installing ArcGIS (arcpy) on Windows, Jupyter notebooks started using the ArcGIS / Windows Python instead of the intended WSL (Ubuntu) Python, even though Python and packages were installed inside WSL.

  • Packages not found (e.g. folium)
  • Mixed Windows ↔ WSL paths
  • Hard-to-debug environment conflicts

Root cause: Jupyter was launched from Windows or bound to an ArcGIS Python kernel.

Goal

  • ✔ Ensure Jupyter uses pure WSL Python
  • ✔ Keep ArcGIS / arcpy untouched and isolated
  • ✔ Create a clean, repeatable setup

Step 1 — Identify the Python Used by the Notebook

Run this cell inside the failing notebook:

import sys
print(sys.executable)
print(sys.path)
❌ Problem:
If you see paths like: 
C:\Program Files\ArcGIS\Pro\...
or 
/mnt/c/Program Files/ArcGIS
Jupyter is using ArcGIS / Windows Python.

Step 2 — Identify the Correct Python in WSL

Run these commands in the Ubuntu terminal (not in Jupyter):

which python
python -c "import sys; print(sys.executable)"
python -c "import folium; print(folium.__version__)"
  • ❌ If the last command fails → folium is not installed
  • ✅ If it works → this is the Python we want Jupyter to use

Step 3 — Clean, Isolated Fix (Recommended)

This method is safe, clean, and cannot affect ArcGIS.

1️⃣ Remove any broken environment

rm -rf ~/wsl-jupyter

2️⃣ Create a fresh virtual environment

python3 -m venv ~/wsl-jupyter
source ~/wsl-jupyter/bin/activate

Verify:

which python

Expected output:

/home/<you>/wsl-jupyter/bin/python

3️⃣ Install required packages

python -m pip install --upgrade pip
python -m pip install jupyterlab folium ipykernel

Verify:

python -c "import folium; print(folium.__version__)"
✅ This must succeed

Step 4 — Register the Kernel (Critical)

python -m ipykernel install --user \
  --name wsl-clean \
  --display-name "Python (WSL Clean)"

This registers a clean kernel that Jupyter can explicitly select.

Step 5 — Launch Jupyter Correctly

From the same activated WSL terminal:

jupyter lab
Important Rules:
  • 🚫 Do NOT launch Jupyter from Windows
  • 🚫 Do NOT open old notebooks yet

Step 6 — Create a New Notebook

  1. Create a new notebook
  2. Select kernel: Python (WSL Clean)
  3. Test:
import sys
print(sys.executable)

Expected output:

/home/<you>/wsl-jupyter/bin/python

Future ToDo / Best Practices

  • Always start Jupyter from WSL
  • Never install Linux packages into ArcGIS Python
  • One virtual environment = one kernel
  • Name kernels clearly (e.g. WSL Clean, WSL GIS)
  • If things break again → delete venv and recreate

Documented for future reference and repeatable setup.
