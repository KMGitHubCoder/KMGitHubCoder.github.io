🧰 Git & GitHub CLI Cheat Sheet

🔐 GitHub CLI Authentication


gh auth login
gh auth status
gh auth logout

📦 Repository Management (gh)


gh repo list
gh repo create test-repo --private --confirm
gh repo create test-repo --public --source=. --remote=origin
gh repo clone username/test-repo
gh repo view --web
gh repo delete username/test-repo --confirm

🐛 Issues


gh issue create --title "Title" --body "Body"
gh issue list
gh issue view 1
gh issue close 1

🧑‍💻 Project Initialization


git init
echo "# Test Repository" > README.md
git status

➕ Staging & Committing


git add README.md
git add .
git commit -m "Initial commit"

🌐 Remote Management


git remote -v
git remote add origin https://github.com/username/repo.git
git remote remove origin

🚀 Push & Pull


git push -u origin main
git pull
git fetch

🌿 Branching


git branch
git branch new-feature
git checkout new-feature
git checkout main
git branch -d new-feature

# Modern commands
git switch main
git switch -c new-feature

🔄 Undo & Fix


git restore README.md
git restore --staged README.md
git commit --amend
git reset --soft HEAD~1
git reset --hard HEAD~1

📜 Logs & Diff


git log
git log --oneline --graph --all
git diff

🧠 Pull Requests & Actions (gh)


gh pr create
gh pr list
gh pr checkout 1
gh pr view --web
gh workflow list
gh run list

🐧 WSL Tip

cd \\wsl$\Ubuntu\home<your-username>
Access WSL filesystem from PowerShell or Windows Explorer.

⚙️ Global Git Configuration


git config --global user.name "Your Name"
git config --global user.email "you@email.com"
git config --global init.defaultBranch main
