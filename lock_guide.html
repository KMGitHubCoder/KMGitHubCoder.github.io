Password Protection Using .htaccess & .htpasswd

This guide explains how to create or reset a username and password for directory protection using .htaccess and .htpasswd.

1. What Are These Files?

  • .htaccess – Controls access rules for a folder
  • .htpasswd – Stores usernames and encrypted passwords
Passwords are encrypted. You cannot recover them, only reset them.

2. Example .htaccess File


AuthType Basic
AuthName "Restricted Area"
AuthUserFile /full/server/path/.htpasswd
Require valid-user

⚠️ The path to .htpasswd must be an absolute server path.

3. Creating a Username & Password (No SSH)

Step 1: Generate a Password Hash (PHP)


php -r "echo password_hash('YOUR_PASSWORD', PASSWORD_BCRYPT) . PHP_EOL;"

Step 2: Create / Edit .htpasswd


username:$2y$10$EXAMPLE_HASH_HERE

Replace:

  • username → your chosen username
  • EXAMPLE_HASH_HERE → the generated hash

4. If You Forgot Username and Password

You cannot recover old credentials. Create new ones.

Option A: Replace Entire .htpasswd File


newuser:NEW_GENERATED_HASH

Save the file and log in using the new credentials.

5. Disable Protection Temporarily (Emergency)

Comment out the authentication lines in .htaccess: 


# AuthType Basic
# AuthName "Restricted Area"
# AuthUserFile /full/server/path/.htpasswd
# Require valid-user

Re-enable them after fixing credentials.

6. File Permissions (Important)

  • .htaccess → 644
  • .htpasswd → 600 or 640

7. Common Mistakes

  • Using relative paths in AuthUserFile
  • Trying to decode passwords
  • Using plain text passwords
  • Wrong file permissions

✅ Your directory is now protected with a secure username and password.
